### 📊 **What is a Combo Chart?**

A **Combo Chart** in Power BI is a **visual that combines a Column Chart and a Line Chart** on the same graph. It’s very useful when you want to **compare two measures** (like sales and profit) over the same category (like time or region).

---

### ✅ **How to Create a Combo Chart**

1️⃣ **Add the Chart**

* Start with a **Line and Stacked Column Chart** (or Line and Clustered Column Chart) visual.

2️⃣ **Set the Axis**

* Drag a **date field** (or category) to the **Shared Axis**.
  👉 This will be the X-axis — e.g., Year.

3️⃣ **Add Columns**

* Drag your first measure to **Column Values** — this shows data as **bars**.
  Example: Average % change for Flats (apartments).

4️⃣ **Add Line**

* Drag your second measure to **Line Values** — this shows data as a **line**.
  Example: Average % change for Semi-Detached houses.

5️⃣ **Check Aggregations**

* Make sure both measures use the **right aggregation** (e.g., Average instead of Sum) so the scale makes sense.

---

### 🔍 **Explore and Refine**

* Use **See Records** (or “Show data point as a table”) to check real numbers.
* You can **include or exclude years** or data points you don’t want.
* Add **Regions** to break columns down by area. (Be careful — too many categories can clutter the chart.)

---

### ⚙️ **Extra Options**

* You can **shade the area** under the line to turn it into an **Area Chart + Column Chart**.
* Adjust **colors** under the Colors section.
* Add **Data Labels** to show exact values — but too many labels can be messy.
* Use a **Secondary Y-Axis** if your line and columns have very different scales.
  🔹 Be careful: the zero point on the secondary axis may not line up with the primary axis, which can confuse viewers.
* **Zoom Slider**: Adds a scroll bar for easier navigation if you have many data points.

---

### ⚠️ **Tips**

✅ Use Combo Charts to compare **two related measures**.
✅ Pick clear, correct aggregations (Average, Sum, etc.).
✅ Adding more lines/regions can help but don’t overload the chart — keep it clear.
✅ If using shaded areas, keep the bars simple so the visual stays readable.
✅ Watch out for confusing double axes — only use them when really needed.

---

### 🎯 **Key Point**

**Combo Charts** help you **show trends and compare multiple things in one place**, but they work best when they are **simple and clear** — too much detail can hide the message.
